# Codex++ 1.0.4

This patch fixes Windows Store ChatGPT startup failures reporting that the process has no package identity after Codex++ installation.

## Fixes

- Start managed Windows Store mirrors with the exact registered package identity and the application ID from its manifest.
- Generate the shared PowerShell launcher, command shim, and shortcuts during install and repair, including when the ASAR patch is already intact.
- Resolve the currently registered version in the same Store package family during repair after an app update. Refuse stale or missing package identities with a repair message and a diagnostic log.
- Preserve launch arguments and support child-process execution under a restricted PowerShell policy without changing the user's persistent execution policy.
- Continue installing the command and Start Menu launchers if the Desktop shortcut cannot be written, and remove the shared launcher during uninstall.

## Verification

- Windows clean-source build and full test suite: 192 passed, 7 platform skips, 0 failures.
- Regression coverage includes repeated installation and repair, unchanged intact ASAR contents, exact package and manifest matching, argument quoting, restricted execution policy, inaccessible Desktop folders, stale package rejection, and Store version resolution.
- The package-context launch was checked locally against ChatGPT Windows Store package `26.915.3509.0`. A real subsequent Store update has not been exercised; version transitions are covered by fixtures.

## Upgrade

Fully quit ChatGPT, run `codexplusplus update`, then run `codexplusplus repair` and open the Codex++ shortcut.

Keep the original Store installation registered. The compatibility launcher uses Windows `Invoke-CommandInDesktopPackage`, a diagnostic API whose behavior beyond package identity and virtualized-resource access is not guaranteed.

External installer wrappers must preserve these generated launchers. Replacing the command shim or shortcut with a direct `ChatGPT.exe` target removes package identity again.
