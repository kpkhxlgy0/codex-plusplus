# Codex++ 1.0.9

This patch keeps Codex++ navigation inside Settings. Home-page chat titles that contain or exactly match native Settings labels no longer cause Codex++ groups to appear in the main sidebar.

## Fixes

- Identify Settings by complete, normalized labels on visible native controls. Ignore hidden controls, injected groups, and nested chat lists in the main navigation.
- Accept a separate Settings navigation region when the main sidebar is also present.
- Remove stale injected groups and active pages when leaving Settings, dispose registered tweak page resources, and restore native content and selection.
- Recheck the accepted Settings surface during delayed cleanup so reused DOM and unrelated page text cannot keep Settings active.

## Verification

- Final 1.0.9 Windows suite: 332 tests, 324 passed, eight platform skips, zero failures. Full build passed.
- Settings regressions cover exact and substring-like chat titles, hidden and nested controls, separate navigation regions, route changes, registered page disposal, and delayed cleanup.
- The user manually installed the fix on Windows and confirmed that the home-page injection problem was resolved. The source fix passed independent review.
- Installer npm package contents match the final build, including the 1.0.9 version, loader, main runtime, and Settings preload files.
- macOS and Linux UI behavior has not been manually verified for this patch.

## Upgrade

Run `codexplusplus update`, then fully quit and reopen Codex to load the updated runtime.

For an existing clone, update it with Git and run `./install.ps1` on Windows or `bash ./install.sh` on macOS/Linux. Fully close Codex before installing on Windows.
