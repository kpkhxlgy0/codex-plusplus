# Codex++ 1.0.13

Config, Tweaks, Tweak Store, and registered tweak pages now appear when you open full-screen Settings from inside Codex, from the system menu, or with the Settings shortcut. Codex++ recognizes the native Settings sidebar even when the page opens without a URL change.

Reopening Settings restores a single copy of each menu item. Codex++ also handles newer section headers and settings controls that finish loading in a background window. Returning to chat releases the Settings page observer.

Update with `codexplusplus update` and restart Codex.
