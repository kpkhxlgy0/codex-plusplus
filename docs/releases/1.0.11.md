# Codex++ 1.0.11

Config, Tweaks, Tweak Store, and registered tweak pages now open in the Settings dialog introduced in recent Codex
desktop builds. Selecting a native settings item restores its content. Closing the dialog restores the chat view.

The installer and updater now use `tar` 7.5.23, `@xmldom/xmldom` 0.9.12, and `brace-expansion` 1.1.22.
The production dependency audit returned zero known vulnerabilities at release validation. The full workspace audit
still reports three affected development packages (`electron`, `extract-zip`, and `esbuild`).

Update with `codexplusplus update` and restart Codex to load the updated settings integration.
