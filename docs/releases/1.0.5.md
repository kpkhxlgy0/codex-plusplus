# Codex++ 1.0.5

This patch restores Codex++ Settings pages and controls after the Codex Desktop 26.924 layout and style changes.

## Fixes

- Mount Config, Tweaks, Tweak Store, and registered tweak settings in the active Settings content area instead of the decorative background surface.
- Restore native settings content when returning to General, and keep custom pages working when the native content or sidebar is rebuilt.
- Show the selected Codex++ sidebar item with the current native highlight, text, and icon styles. Remove the native selection while a custom page is active and restore it when returning.
- Render shared switches with the native blue enabled track, grey disabled track, and white thumb. Config and Tweaks retain their existing save callbacks and disabled-while-saving behavior.

## Verification

- Windows full test suite: 212 passed, 7 platform skips, 0 failures. Build passed.
- Focused Settings regression tests: 30 passed, covering content targeting, remounts, selection restoration, switch appearance, and save callbacks.
- Runtime deployment, file hashes, status, and doctor passed on Codex Desktop 26.924.22138, Windows Store package 26.924.2738.0.
- Settings content, sidebar selection, and switch appearance were manually accepted on that Windows installation. Other platform UI behavior has not been manually verified for this patch.

## Dependency audit

The audit reports six affected dependency packages (one critical, four high, and one low). Dependency versions are unchanged from 1.0.4; these advisories are not resolved by this Settings patch.

## Known limitation

This release covers the Codex++ Settings integration. The separately installed Feishu tweak's conversation-creation bridge is not yet adapted to the new desktop request interface; its earlier offline tests do not establish compatibility with this Codex version. No third-party tweak implementation or Store approval pin is changed by this release.

## Upgrade

Run `codexplusplus update`, then fully quit and reopen Codex to load the updated runtime.
