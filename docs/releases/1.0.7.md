# Codex++ 1.0.7

Prevent unnecessary tweak reloads when Git metadata or dependency files change inside a development link.

## Fixes

- Ignore complete `.git` and `node_modules` path segments, including the directory entries themselves, with either Windows or POSIX path separators.
- Keep watching source files, manifests, build outputs, other dot directories and similarly named paths. Ordinary tweak edits still reload.
- Include the corrected watcher and version in the runtime shipped with install and repair.

## Verification

- Full Windows suite: 218 passed, seven platform skips, zero failures. Build passed.
- Real Chokidar tests use a development directory link. They reproduce unwanted Git/dependency events before the fix, verify those trees are excluded afterward, and verify source/manifest edits still emit events.
- Independent review found no material issues. Dependency versions and runtime APIs are unchanged.
- The implementation bundle was staged and hash-verified on two existing Windows installations. Recreating the main-process watcher in those running applications requires a full restart; post-restart behavior in those two applications has not yet been observed. This release does not claim a completed live restart check.

## Upgrade

Run `codexplusplus update`, then fully quit and reopen Codex. Reloading tweaks alone does not replace the main-process watcher.

Session Stats v0.4.2 separately fixes native subagent statistics and reduces remote refresh-request latency. Install that tweak update as well to receive both sets of fixes.
