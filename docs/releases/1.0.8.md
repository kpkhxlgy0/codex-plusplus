# Codex++ 1.0.8

Running `install.ps1` or `install.sh` from an existing source tree now installs that local source, including uncommitted changes. Previously, both scripts downloaded GitHub source even when launched from a clone.

## Changes

- Detect local source from the saved script's location, install dependencies, and rebuild before installation. Running the script by absolute path from another directory also works.
- Keep piped Bash and PowerShell `Invoke-Expression` installations on the GitHub download path, including when the caller is inside a checkout.
- Refuse to replace Git checkouts, directories inside or containing them, linked destinations, unrelated nonempty directories, or protected previous-installation backups.
- Stop when local `npm ci` fails and preserve the existing lockfile. Relative `--app` arguments retain the caller's working directory.
- Run local dependency installation and builds as the invoking user under sudo, without recursively changing checkout ownership.
- Protect local checkouts and backup directories from replacement by manual and watcher-driven source updates. Maintain a checkout with Git and rerun its local installer.
- Make watcher installation opt-in: default local and online installs leave it disabled. Reinstalling without `--watcher` removes a previously configured watcher instead of leaving a task bound to the old CLI source. Pass `--watcher` to enable it; `--no-watcher` remains supported. Repair preserves an already configured watcher.

## Verification

- Full Windows suite: 299 passed, eight platform skips, zero failures. Build passed.
- Real Windows reinstall used the existing local checkout. Installed runtime hashes and CLI launchers matched that checkout; configuration and all three installed tweaks were preserved.
- PowerShell and Bash regressions cover local and online entry points, argument forwarding, dependency failures, protected destinations and backups, archive rotation, and linked-directory handling.
- A real Windows 8.3 temporary-path alias regression verifies successful online bootstrap cleanup. CI normalizes temporary-path spelling and TypeScript line endings across platforms.
- Compiled CLI checks against the real checkout confirmed that forced manual and watcher updates protect the repository. The checks used isolated user-data directories and disabled repair.
- CI runs tests and builds on Windows, macOS, and Linux. Independent review found no remaining material issues.
- Live application installation was verified on Windows; application installation on macOS and Linux remains unverified.

## Installation

For an existing clone, update it with Git and run `./install.ps1` on Windows or `bash ./install.sh` on macOS/Linux. Dependencies may still require network access. Fully close Codex before installing on Windows.

The watcher is disabled by default. To opt in, pass `--watcher` to the local script or run `codexplusplus install --watcher`.

The documented online commands continue to download GitHub source. `CODEX_PLUSPLUS_SOURCE_DIR` controls only the online installation destination.

Session Stats and its Store entry are unchanged.
